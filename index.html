Bloco 1 · O que é JavaScript?

Uma linguagem criada em dez dias

O JavaScript nasceu em 1995, na Netscape, escrito por Brendan Eich em cerca de dez dias. Ele passou por alguns nomes até chegar ao que conhecemos hoje.

Um pouco de história

  • O primeiro protótipo tinha o nome-código Mocha, depois foi renomeado brevemente para LiveScript
  • Foi renomeado para JavaScript por motivos de marketing, para aproveitar a popularidade do Java — as duas linguagens não têm relação técnica entre si
  • Padronizado em 1997 como ECMAScript, então "JavaScript" e "ECMAScript" hoje significam quase a mesma coisa
  • Hoje é uma das linguagens de programação mais usadas do mundo, rodando em praticamente todo navegador

Para que ele é usado?

  • Tornar páginas web interativas — validação de formulários, animações, conteúdo dinâmico
  • Construir aplicações front-end completas (a lógica por trás de botões, menus, atualizações em tempo real)
  • Programação do lado do servidor, com Node.js
  • Aplicativos mobile, aplicativos desktop e até pequenos dispositivos embarcados

Bloco 1 · O que é JavaScript?

Dois lugares onde vamos executá-lo hoje

O JavaScript precisa de um "motor" para ser executado. Hoje vamos usar dois: o seu navegador e, opcionalmente, o Node.js na sua máquina.

No navegador

Todo navegador (Chrome, Firefox, Safari, Edge) tem um motor de JavaScript embutido. O código pode ficar em:

  • Uma tag <script> dentro de uma página HTML
  • Um arquivo .js externo, vinculado a partir do HTML
  • O console de desenvolvedor do navegador, para experimentos rápidos

No servidor, com Node.js

O Node.js pega o mesmo motor de JavaScript que roda no Chrome e permite executá-lo fora do navegador — em um servidor, ou direto pelo terminal.

  • Usado para APIs de back-end, ferramentas de build e scripts de linha de comando
  • Não é obrigatório para este workshop, mas vale instalar se você quiser continuar depois

Cenário do mundo real

Uma página de checkout que deixa o botão "Pagar" desabilitado até todos os campos serem preenchidos é JavaScript de navegador. O serviço que de fato cobra o cartão depois é, muito provavelmente, Node.js ou outra linguagem do lado do servidor.

Bloco 2 · Configuração do ambiente

O que você precisa na sua máquina

Três coisas, e você já tem pelo menos uma delas.

1. Um navegador

Qualquer navegador moderno funciona. Vamos usar as ferramentas de desenvolvedor dele o tempo todo, então guarde o atalho:

  • Windows/Linux: F12 ou Ctrl+Shift+I
  • macOS: Cmd+Option+I
  • Abra a aba Console — é lá que aparecem as saídas e os erros

2. Um editor de código

Recomendamos o Visual Studio Code (gratuito) pelo terminal integrado e suporte a JavaScript, mas qualquer editor de texto funciona.

3. Node.js (opcional hoje)

Só é necessário se você quiser executar JavaScript fora do navegador. Para verificar se já está instalado, abra um terminal e rode:

terminal 
node --version
npm --version

Se aparecerem números de versão, está tudo certo. Se aparecer "command not found", baixe o instalador LTS em nodejs.org e reabra o terminal.

Bloco 3 · Primeiros passos

Conectando um arquivo .js a uma página web

Em projetos reais, o JavaScript quase sempre fica em seu próprio arquivo, vinculado ao HTML com uma tag <script>.

index.html 
<!DOCTYPE html>
<html>
  <head>
    <title>Minha Página</title>
  </head>
  <body>
    <h1>Olá!</h1>

    <!-- colocado logo antes de </body> para que -->
    <!-- o conteúdo da página carregue antes do script -->
    <script src="script.js"></script>
  </body>
</html>

Comentários e algumas regras básicas

  • // comentário de uma linha — ignorado pelo JavaScript
  • /* comentário de várias linhas */ — abrange várias linhas
  • O JavaScript diferencia maiúsculas de minúsculas: minhaVar e minhavar são diferentes
  • O ponto e vírgula ; encerra uma instrução — o JavaScript muitas vezes consegue inferir isso, mas escrevê-lo explicitamente evita surpresas
  • Espaços e indentação não afetam a execução, mas um estilo consistente torna o código muito mais fácil de ler

Bloco 4 · Sintaxe básica

Guardando valores em variáveis

Três palavras-chave declaram uma variável. Use const por padrão, let quando o valor vai mudar, e evite var em código novo.

variaveis.js

var vs let vs const

  • const — não pode ser reatribuída; use sempre que não precisar mudar o valor
  • let — pode ser reatribuída; tem escopo limitado ao bloco onde foi declarada
  • var — a palavra-chave original; tem regras de escopo mais soltas que causam bugs, hoje geralmente evitada

Regras de nomenclatura

  • Apenas letras, dígitos, _ e $; não pode começar com um dígito
  • Convenção: camelCase para variáveis e funções

Comparando e combinando valores

Além da aritmética (próximo bloco), esses operadores aparecem em quase todo script.

Operadores de comparação e lógicos

  • === / !== — igual / diferente estrito (também verifica o tipo — prefira estes)
  • == / != — igual / diferente flexível (converte os tipos antes — fácil de usar errado)
  • > < >= <= — comparações padrão
  • && (e), || (ou), ! (não)

Bloco 5 · Operadores aritméticos

Fazendo contas em JavaScript

Os operadores padrão, além de uma pegadinha que confunde quase todo mundo na primeira vez.

Operadores

  • + soma   - subtração
  • * multiplicação   / divisão
  • % resto da divisão (módulo)
  • ** potência (exponenciação)

A ordem de operações padrão se aplica: ** antes de * /, antes de + -, e parênteses () têm prioridade sobre tudo.
