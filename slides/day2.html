O que muda hoje

No Dia 1, todo código rodava "em linha reta", de cima para baixo. Hoje o programa vai aprender a tomar decisões — a mesma linha de código vai se comportar diferente dependendo dos dados.

É exatamente esse comportamento condicional que torna um programa capaz de resolver problemas reais, e não só calcular valores fixos.

Antes de começar o Dia 2

Pedindo um valor para quem usa o programa

Até agora todo valor vinha fixo no código (let idade = 15;).

A função prompt() deixa a pessoa que está usando o programa digitar o valor na hora.

Como funciona

  • prompt("mensagem") abre uma caixa de diálogo no navegador pedindo um valor
  • A pessoa digita e clica em OK (ou Cancelar)
  • O valor devolvido é sempre um texto (string), mesmo que pareça um número
  • Para fazer contas com o resultado, converta com Number()

Introdução aos algoritmos

O que é um algoritmo?

Antes de falar de código, vamos falar da ideia por trás dele.

Uma definição simples

Um algoritmo é uma sequência finita e ordenada de passos para resolver um problema ou realizar uma tarefa.

Isso não tem nada de exclusivo da programação — você segue algoritmos várias vezes por dia sem perceber.

  • Uma receita de bolo é um algoritmo
  • O manual de montagem de um móvel é um algoritmo
  • As instruções do Google Maps até aqui são um algoritmo

Por que isso importa para programar?

Escrever código é, na prática, traduzir um algoritmo (em português, ou em um fluxograma, ou só na sua cabeça) para uma linguagem que o computador entende.

Quanto mais claro o algoritmo antes de programar, mais fácil é escrever o código — e mais fácil é encontrar o erro quando algo não funciona.

Introdução aos algoritmos

Da instrução do dia a dia ao código

O mesmo algoritmo, escrito de duas formas: em português e em JavaScript.

Algoritmo: "posso atravessar a rua?"

  1. Olhe para o sinal de pedestres
  2. Se o sinal estiver verde, atravesse
  3. Se não, espere até o sinal ficar verde

Repare na palavra "se" — é exatamente isso que uma estrutura condicional representa em código, e é o assunto do próximo bloco de hoje.

16h · Estruturas condicionais

A palavra-chave if

if executa um bloco de código somente quando uma condição é verdadeira (true).

Anatomia de um if

  • A condição fica entre parênteses ( ) e deve resultar em true ou false
  • O bloco de código fica entre chaves { }
  • Se a condição for false, o bloco simplesmente é ignorado
  • Os operadores de comparação do Dia 1 (===, >, >=...) são exatamente o que entra na condição

16h · Estruturas condicionais

else e else if

else executa quando a condição do if é falsa. else if permite encadear mais de uma condição.

else-basico.js

Regras rápidas

  • else nunca tem sua própria condição — ele é "todo o resto"
  • else if é avaliado em ordem, de cima para baixo; o primeiro que for verdadeiro "vence" e os demais são ignorados
  • Uma cadeia de if/else if/else sempre executa exatamente um dos blocos

· Introdução ao debug

O que fazer quando o código não funciona

Debugar é o processo de descobrir por que o código não está se comportando como o esperado. Edite o código ao lado para consertar o bug antes de executar.

Um roteiro simples

  1. Leia a mensagem de erro no console com calma — ela quase sempre diz a linha e o tipo de problema
  2. Use console.log() para "espiar" o valor de uma variável em pontos-chave do código
  3. Compare o que você esperava ver com o que realmente apareceu
  4. Mude uma coisa de cada vez, e rode de novo — mudar tudo ao mesmo tempo dificulta saber o que resolveu

Exercício 1 — Faixa etária

Dada uma idade, classifique em "Criança" (até 12 anos), "Adolescente" (13 a 17) ou "Adulto" (18 ou mais).

Faixa etária

10 min
faixa-etaria.js
Dica
Comece pela condição mais restritiva ou pela mais simples de descrever — por exemplo, primeiro verifique idade <= 12, depois idade <= 17 em um else if, e deixe o else final cobrir os adultos.
Solução
if (idade <= 12) { console.log("Criança"); } else if (idade <= 17) { console.log("Adolescente"); } else { console.log("Adulto"); }

Exercício 2 — Média UnB

Dada uma média final, calcule a menção usando a escala da UnB: SS (9,0 a 10), MS (7,0 a 8,9) ou MM (5,0 a 6,9). Abaixo de 5,0, considere reprovado.

Média UnB

10 min
media-unb.js
Dica
É a mesma estrutura do exercício de faixa etária, só que com números diferentes. Comece pela nota mais alta (media >= 9) e vá descendo com else if.
Solução
if (media >= 9) { console.log("SS"); } else if (media >= 7) { console.log("MS"); } else if (media >= 5) { console.log("MM"); } else { console.log("Reprovado"); }

Exercício 3 — Calculadora simples

Dados dois números e uma operação ("+", "-", "*" ou "/"), calcule e mostre o resultado.

Calculadora simples

10 min
calculadora.js
Dica
Compare operacao com cada símbolo usando ===, um if/else if por operação, e use os operadores aritméticos do Dia 1 dentro de cada bloco.
Solução
if (operacao === "+") { console.log(numeroA + numeroB); } else if (operacao === "-") { console.log(numeroA - numeroB); } else if (operacao === "*") { console.log(numeroA * numeroB); } else if (operacao === "/") { console.log(numeroA / numeroB); } else { console.log("Operação inválida"); }

Cenário do mundo real

Esse mesmo padrão — comparar um texto para decidir qual cálculo aplicar — é como apps de delivery calculam frete, descontos e taxas diferentes dependendo da forma de pagamento escolhida.
