O que muda hoje

Até agora, cada instrução do seu código rodava uma única vez, na ordem em que foi escrita. Se quiséssemos repetir algo dez vezes, tínhamos que escrever (ou chamar) dez vezes.

Hoje aprendemos os laços de repetição: uma forma de dizer "repita isso enquanto uma condição for verdadeira" ou "repita isso um número específico de vezes" — sem copiar e colar nada.

Laços de repetição

Evitando repetir o mesmo código à mão

Um loop repete um bloco de código automaticamente, enquanto uma condição for verdadeira.

O problema que loops resolvem

  • Repetir uma linha 5 vezes é chato de escrever — e repetir 500 vezes é inviável
  • Um loop deixa o número de repetições no controle de uma condição ou de um contador, não do quanto você copiou e colou
  • É a mesma ideia das funções (Dia 4): escrever a lógica uma vez, reaproveitar quantas vezes precisar

Laços de repetição

while: repita enquanto for verdadeiro

while (condição) { ... } repete o bloco enquanto a condição continuar verdadeira.

Como funciona

  • Antes de cada repetição, o JavaScript verifica a condição
  • Se for true, o bloco roda de novo; se for false, o loop termina
  • É essencial que algo dentro do loop eventualmente torne a condição falsa — senão o loop nunca para (mais sobre isso no próximo slide)

Programação em dupla

Antes de executar, peça para a pessoa ao lado prever quantas linhas de "Contando" vão aparecer. Depois tentem juntos: e se o loop começasse com contador = 0? E se a condição fosse contador < 5?

Laços de repetição

O bug mais clássico de todo loop

Se a condição de um while nunca ficar falsa, o loop roda para sempre — e trava a aba do navegador.

Como esse bug acontece

É muito comum esquecer de atualizar a variável que controla a condição. Sem isso, a condição nunca muda, e o loop nunca termina.

Não execute o código ao lado — ele foi propositalmente deixado sem o Run, exatamente para mostrar o erro sem travar a página.

nao-execute.js
// ⚠️ Este código nunca termina — é só para leitura
let contador = 1;

while (contador <= 5) {
  console.log("Contando: " + contador);
  // Faltou "contador = contador + 1;"
  // Sem isso, "contador" nunca muda, e a
  // condição nunca fica falsa.
}

Se a sua aba travar

Se você acidentalmente rodar um loop infinito de verdade, a aba pode parar de responder. Feche a aba (ou a janela) e abra o material de novo — nenhum progresso salvo é perdido, já que os slides não guardam o código entre uma execução e outra.

Laços de repetição

for: contando em uma única linha

for (início; condição; incremento) { ... } junta as três partes de um loop contado em um só lugar.

As três partes do for

  • let i = 1 — roda uma vez, antes de tudo (a inicialização)
  • i <= 5 — verificada antes de cada repetição (a condição)
  • i++ — roda ao final de cada repetição (o incremento)

Como o incremento já faz parte da própria linha do for, é mais difícil esquecer de atualizar a variável — por isso for é a escolha mais comum quando você sabe quantas vezes quer repetir.

Laços de repetição

Escolhendo entre for e while

Os dois repetem código — a diferença está em quando cada um encaixa melhor.

Uma regra prática

  • Use for quando você sabe (ou consegue calcular) quantas vezes quer repetir
  • Use while quando a repetição depende de uma condição que só se resolve com o tempo, não de uma contagem fixa

Combinando repetição com decisões

Um if/else dentro de um loop permite tratar cada repetição de um jeito diferente.

par-ou-impar.js

Um padrão extremamente comum

"Percorrer uma sequência de itens e decidir algo sobre cada um" é um dos padrões mais usados em programação — e é só um loop com um if dentro.

Cenário do mundo real

Uma loja online que mostra só os produtos "em promoção", ou um app de mensagens que destaca só as conversas "não lidas", está fazendo exatamente isso: percorrendo uma lista e aplicando uma condição a cada item.

Juntando Dia 4 e Dia 5

Uma função pode usar um loop por dentro, e devolver só o resultado final com return.

somar-ate.js

Por que isso é poderoso

  • Quem chama somarAte(5) não precisa saber que existe um loop lá dentro — só se importa com o resultado
  • A variável soma é local à função (escopo, Dia 4): cada chamada começa do zero
  • Esse é o mesmo padrão por trás de praticamente qualquer cálculo "some todos", "conte quantos" ou "encontre o maior" que você vai escrever no futuro

Exercício 1 — Tabuada de um número

Use um for para imprimir a tabuada de numero, de 1 até 10 (ex.: "7 x 1 = 7").

Tabuada

10 min
tabuada.js
Dica
Use um for de i = 1 até i <= 10, e dentro dele monte a string com numero * i.
Solução
for (let i = 1; i <= 10; i++) { console.log(numero + " x " + i + " = " + (numero * i)); }

Exercício 2 — Contagem regressiva

Use um while para contar de 10 até 1, e depois mostre "Fim!".

Contagem regressiva

10 min
regressiva.js
Dica
Lembre-se de diminuir numero a cada volta do loop — sem isso, ele nunca termina (o bug do slide de loops infinitos).
Solução
while (numero >= 1) { console.log(numero); numero = numero - 1; } console.log("Fim!");

Exercícios

Exercício 3 — Soma dos números pares

Some todos os números pares de 1 a 20, usando for + if, e mostre o resultado.

Soma dos números pares

10 min
soma-pares.js
Dica
Use i % 2 === 0 (Dia 1) para saber se um número é par, e some só esses em soma.
Solução
for (let i = 1; i <= 20; i++) { if (i % 2 === 0) { soma = soma + i; } } console.log(soma);

Exercício 4 — Função com loop (fatorial)

Escreva uma função fatorial(numero) que calcula o fatorial (ex.: fatorial de 5 é 5×4×3×2×1 = 120), usando um for dentro dela.

Função com loop

15 min
fatorial.js
Dica
Comece com let resultado = 1; antes do loop, e multiplique resultado por i a cada volta — parecido com o somarAte que vimos antes, mas multiplicando em vez de somar.
Solução
function fatorial(numero) { let resultado = 1; for (let i = 1; i <= numero; i++) { resultado = resultado * i; } return resultado; } console.log(fatorial(5)); console.log(fatorial(3));
