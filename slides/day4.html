Funções

Evitando repetir o mesmo código

Uma função empacota um pedaço de lógica com um nome, para que você possa reaproveitá-lo em vez de copiar e colar.

O que funções trazem

  • Reutilização — escreva a lógica uma vez, use quantas vezes precisar
  • Organização — um nome bem escolhido explica o que aquele bloco faz
  • Manutenção — precisou corrigir algo? Muda em um lugar só, não em cada cópia espalhada pelo código

Funções

Sua primeira função

function declara a função; o nome dela seguido de () a executa ("chama").

Anatomia de uma função

  • function — palavra-chave que inicia a declaração
  • nomeDaFuncao — escolhido por você, segue as mesmas regras de nomes de variáveis
  • () — onde ficam os parâmetros (vazio por enquanto)
  • { } — o bloco de código que roda quando a função é chamada
  • Declarar a função não executa o código dentro dela — isso só acontece quando você a chama

Funções

Parâmetros: dados que entram na função

Parâmetros deixam a mesma função se comportar diferente a cada chamada.

Regras importantes

  • Os valores enviados na chamada (argumentos) são recebidos na ordem em que os parâmetros foram declarados
  • Trocar a ordem na chamada muda o resultado — a função não "adivinha" o que cada valor significa
  • Um parâmetro pode ter um valor padrão, usado quando nada é enviado naquela posição

Funções

return: devolvendo um valor

Uma função pode devolver um valor para quem a chamou, usando return — diferente de apenas imprimir algo no console.

console.log vs. return

  • console.log(...) só mostra algo no console — o valor não fica disponível para o resto do código
  • return valor; devolve o valor para quem chamou a função, que pode guardá-lo em uma variável
  • Uma função sem return devolve undefined automaticamente
  • return também encerra a função na hora — nenhuma linha depois dele é executada

Funções

Arrow functions (funções de seta)

Uma forma mais curta de escrever uma função, usando => no lugar da palavra function.

arrow.js

O que muda, na prática

  • Arrow functions são guardadas em uma variável (const), não têm um nome próprio como function nome()
  • Com um único parâmetro, os parênteses podem ser omitidos: a => a * 2
  • Com uma única expressão no corpo, as chaves { } e o return podem ser omitidos

Cenário do mundo real

Arrow functions aparecem o tempo todo como "funções de uma linha" passadas para outras funções — algo muito comum quando você começar a trabalhar com listas de dados no futuro.

Funções

Escopo: onde uma variável "existe"

Uma variável declarada dentro de uma função só existe ali dentro — esse é o escopo local.

Duas regras simples

  • Escopo global: uma variável declarada fora de qualquer função pode ser usada em qualquer lugar do código
  • Escopo local: uma variável declarada dentro de uma função só existe enquanto essa função está rodando, e só é visível ali dentro
  • Tentar usar uma variável local fora da função onde ela foi criada gera um erro (ReferenceError)

Exercícios

Exercício 1 — Função de saudação

Escreva uma função saudacao(nome) que retorna a frase "Olá, <nome>! Seja bem-vindo(a).". Depois, chame a função e mostre o resultado com console.log.

Função de saudação

10 min
saudacao.js
Dica
Lembre-se de usar return dentro da função. Chamar a função sozinha (saudacao("Ana");) não mostra nada — você precisa colocar a chamada dentro de um console.log(...).
Solução
function saudacao(nome) { return "Olá, " + nome + "! Seja bem-vindo(a)."; } console.log(saudacao("Ana"));

Exercício 2 — Calculadora de área

Escreva uma função areaRetangulo(largura, altura) que retorna a área (largura × altura). Teste com pelo menos dois retângulos diferentes.

Calculadora de área

10 min
area.js
Dica
É o mesmo cálculo de área do Dia 1 (multiplicação), só que agora empacotado dentro de uma função com dois parâmetros.
Solução
function areaRetangulo(largura, altura) { return largura * altura; } console.log(areaRetangulo(4, 5)); console.log(areaRetangulo(10, 2));

Exercício 3 — Verificação de maioridade

Escreva uma função verificarMaioridade(idade) que retorna "Maior de idade" ou "Menor de idade". Teste com pelo menos dois valores diferentes.

Verificação de maioridade

10 min
maioridade.js
Dica
É o mesmo if/else do Dia 2, só que agora, em vez de usar console.log dentro de cada bloco, use return para devolver o texto.
Solução
function verificarMaioridade(idade) { if (idade >= 18) { return "Maior de idade"; } else { return "Menor de idade"; } } console.log(verificarMaioridade(15)); console.log(verificarMaioridade(20));

Exercício 4 — Convertendo para arrow function

Reescreva a função abaixo como uma arrow function, guardada em uma const chamada verificarMaioridadeSeta.

Convertendo para arrow function

10 min
arrow-exercicio.js
Dica
Troque function nome(parametros) { ... } por const nome = (parametros) => { ... };. O conteúdo de dentro do corpo pode continuar exatamente igual.
Solução
const verificarMaioridadeSeta = (idade) => { if (idade >= 18) { return "Maior de idade"; } else { return "Menor de idade"; } }; console.log(verificarMaioridadeSeta(20));
