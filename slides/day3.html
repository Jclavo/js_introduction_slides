Manipulação do DOM

Uma revisão rápida de HTML

Antes de manipular a página com JavaScript, vale relembrar como ela é montada.

As peças básicas

  • Um elemento é escrito com uma tag de abertura e fechamento: <p>texto</p>
  • Um elemento pode ter atributos, como id e class, que ajudam a identificá-lo
  • Elementos podem ficar aninhados dentro de outros, formando uma hierarquia de pai e filho
pagina.html
<div id="app">
  <h1 class="titulo">Olá!</h1>
  <p id="texto">
    Este parágrafo está dentro
    da div "app".
  </p>
</div>

Manipulação do DOM

O que é o DOM?

DOM significa Document Object Model — a representação da sua página HTML como uma árvore de objetos que o JavaScript consegue ler e alterar.

Por que isso importa

Quando o navegador carrega uma página HTML, ele constrói essa árvore automaticamente na memória. Cada tag vira um "nó" que o JavaScript pode acessar através do objeto global document.

É por isso que um clique em um botão consegue, na mesma página e sem recarregar nada, trocar um texto, mudar uma cor ou mostrar uma nova seção.

Manipulação do DOM

getElementById

A forma mais direta de pegar um elemento: pelo valor exato do seu atributo id.

Como funciona

  • document.getElementById("meuId") devolve o elemento com aquele id
  • Como id deve ser único na página, o retorno é sempre um único elemento (ou null, se não existir)
  • A partir do elemento, você pode ler ou mudar o que quiser nele

Manipulação do DOM

querySelector

Mais flexível: usa os mesmos seletores do CSS para encontrar elementos.

Como funciona

  • document.querySelector(".minhaClasse") devolve o primeiro elemento que combina com o seletor
  • Funciona com classe (.classe), id (#id), tag (p) e combinações
  • querySelectorAll(...) devolve todos os elementos que combinam, não só o primeiro

Manipulação do DOM

Trocando o conteúdo de um elemento

textContent troca só o texto. innerHTML também entende tags HTML dentro do valor.

Duas opções, uma diferença importante

  • elemento.textContent = "..." troca o texto puro, sem interpretar tags
  • innerHTML é poderoso, mas nunca deve receber texto digitado por um usuário sem cuidado — é uma porta de entrada comum para ataques

Manipulação do DOM

Trocando o estilo de um elemento

Você pode mudar propriedades de CSS direto pelo JavaScript, ou ligar/desligar classes inteiras com classList.

Duas formas de mudar o estilo

  • elemento.style.[propriedade] = "valor" muda uma propriedade CSS específica
  • Nomes com hífen no CSS viram camelCase no JS: background-color vira backgroundColor

Manipulação do DOM

Reagindo ao que a pessoa faz na página

Um evento é algo que acontece na página — um clique, uma tecla pressionada, um campo preenchido. addEventListener "escuta" esse evento e roda uma função quando ele acontece.

sintaxe.js
let elemento = document.getElementById("meuId");

elemento.addEventListener("click", function () {
  // roda toda vez que o elemento for clicado
  console.log("Cliquei!");
});

Alguns eventos comuns

  • "click" — a pessoa clicou no elemento
  • "keydown" / "keyup" — uma tecla foi pressionada ou solta
  • "input" — o valor de um campo de texto mudou
  • "submit" — um formulário foi enviado
  • "mouseover" — o mouse passou por cima do elemento

Cuidado, um bug comum

Se você clicar em "Executar" mais de uma vez sem restaurar antes, cada clique no botão vai contar em dobro (ou triplo) — isso acontece porque cada execução registra um novo listener, sem remover o anterior. Use "Restaurar demonstração" para recomeçar do zero.

O objeto do evento

A função registrada com addEventListener recebe automaticamente um objeto (aqui chamado evento) com detalhes do que aconteceu.

Para teclado, evento.key diz exatamente qual tecla foi pressionada — de letras a teclas especiais como "Enter" ou "Backspace".

Exercício

Crie um alternador de tema

Combine tudo o que vimos hoje: seleção, conteúdo, estilo e eventos.

Alternador de tema

15 min

Complete o código para que, ao clicar no botão "Alternar", a caixa abaixo troque o texto entre "Modo claro" e "Modo escuro" e troque sua cor de fundo entre um tom claro e um tom escuro.

exercicio-tema.js

Elemento de demonstração

Modo claro
Dica
Crie uma variável let escuro = false; fora do listener. Dentro da função do clique, inverta o valor (escuro = !escuro;) e use if/else para decidir o texto e a cor com base nela — igual ao if/else do Dia 2.
Solução
let escuro = false; botao.addEventListener("click", function () { escuro = !escuro; if (escuro) { caixa.textContent = "Modo escuro"; caixa.style.backgroundColor = "#111111"; caixa.style.color = "#ffffff"; } else { caixa.textContent = "Modo claro"; caixa.style.backgroundColor = "#ffffff"; caixa.style.color = "#111111"; } });

Desafio opcional

Adicione uma terceira opção de tema (por exemplo, "Modo colorido") e use uma variável numérica em vez de um booleano para alternar entre os três.
